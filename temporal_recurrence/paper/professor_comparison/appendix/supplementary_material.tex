\section{Analytical Memory Footprint and Parameter Accounting}
\label{app:memory_accounting}

For $N$ nodes, memory dim $d_m$, key dim $d_k$, and $K$ stored checkpoints (single-precision float32, $4$ bytes), RAM footprint is:
\begin{equation}
    M_{\text{RAM}} = \frac{4 (N d_m + K d_k + K N d_m)}{1024} \text{ KB}.
\end{equation}
For $N = 300, d_m = 64, d_k = 64, K = 10$, $M_{\text{RAM}} = \mathbf{827.5\text{ KB}}$. For $N = 10,000, K = 20$, $M_{\text{RAM}} \approx 52.5\text{ MB}$, confirming modest memory requirements.

\section{Real-World Recurrence Episode Specifications}
\label{app:real_world}

Natural recurrence episodes in SNAP continuous-time datasets:
\begin{itemize}
    \setlength{\itemsep}{0pt}
    \item \textbf{SNAP CollegeMsg} ($1,899$ nodes, $59,835$ interactions): Weekly binned non-overlapping windows. \textbf{Ep 1}: W11 ($\mathcal{A}_1$) $\to$ W12 ($\mathcal{B}$) $\to$ W13 ($\mathcal{A}_2$); \textbf{Ep 2}: W8 $\to$ W9--18 (10-wk distractor) $\to$ W19; \textbf{Ep 3}: W11 $\to$ W12--13 $\to$ W14; \textbf{Ep 4}: W10 $\to$ W11--12 $\to$ W13.
    \item \textbf{SNAP Bitcoin-OTC} ($5,881$ accounts, $35,592$ ratings): Four multi-month partitions isolating cohesive merchant trust clusters active in initial cycles ($\mathcal{A}_1$), dormant during consolidation ($\mathcal{B}$), and reactivating in subsequent market cycles ($\mathcal{A}_2$).
\end{itemize}
Negative pairs were sampled uniformly at random per timestep using deterministic PRNG offsets ($seed + t$).
