Table~\ref{tab:canonical_baselines} and Figure~\ref{fig:tb_response_curve} summarize link prediction performance across distractor durations $T_B \in \{25, 50, 100, 200\}$ on the canonical synthetic benchmark:
\begin{itemize}
    \item \textbf{Heuristic vs. Neural Gap on Unfeatured Graphs}: Explicit structural heuristics (Current-Only: $0.7600$, Historical Retrieval Probe: $0.7588$, Historical Oracle: $0.7876$) achieve high raw AP because they directly compute topological common neighbor intersection counts. In contrast, unfeatured neural message passing on randomly initialized node IDs converges to $\text{AP} \approx 0.652$.
    \item \textbf{Random Retrieval Decay}: Random historical snapshot selection exhibits monotonic degradation as distractor length increases ($0.7423 \to 0.7193$), demonstrating that uniform temporal sampling is severely corrupted by distractor snapshots.
    \item \textbf{Neural Stability}: Continuous TGN and MA-TGN maintain consistent performance across all distractor durations with minimal cross-seed variance ($\sigma < 0.0015$).
\end{itemize}

\subsection{Recurrent Memory Capacity Scaling}
\label{sec:results_capacity}

\begin{figure}[t]
    \centering
    \includegraphics[width=\columnwidth]{figures/fig3_capacity_scaling.pdf}
    \caption{\textbf{Recurrent Memory Capacity Scaling ($d_m$) across $T_B$.} Expanding continuous node memory dimension from $d_m=16$ to $d_m=256$ yields marginal gains without eliminating distractor interference.}
    \label{fig:capacity_scaling}
\end{figure}

To evaluate whether expanding recurrent state dimensions eliminates temporal interference, we varied node memory size $d_m \in \{16, 32, 64, 128, 256\}$ across $T_B \in \{10, 50, 100, 200\}$ (Figure~\ref{fig:capacity_scaling}). Quadrupling capacity from $d_m = 64$ to $d_m = 256$ increases trainable parameters by $412\%$ ($45,697 \to 234,113$) while yielding negligible performance improvements ($+0.0076$ AP at $T_B=100$). This establishes that continuous capacity scaling alone does not resolve sequential overwriting.

We explicitly decompose recurrence into exact edge overlap versus structural community recurrence (Table~\ref{tab:exact_structural} and Figure~\ref{fig:recurrence_decomposition}):
\begin{itemize}
    \item \textbf{Condition A (Exact Recurrence)}: High pairwise persistence yields high EdgeBank performance ($0.8884$).
    \item \textbf{Condition B (Structural Recurrence)}: When interaction topologies share community rules without exact edge overlap, EdgeBank degrades to $0.5774$, while structural retrieval maintains an advantage ($\Delta\text{AP} = +0.0351$).
    \item \textbf{Control ($\mathcal{A} \to \mathcal{B} \to \mathcal{C}$)}: When an unobserved regime $\mathcal{C}$ is introduced, continuous neural models drop to chance level ($0.4990$).
\end{itemize}
