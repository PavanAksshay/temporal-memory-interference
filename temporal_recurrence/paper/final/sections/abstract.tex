\begin{abstract}
Continuous temporal graph neural networks continuously compress sequential graph interactions into evolving recurrent node memory vectors. However, in real-world systems, previously relevant structural interaction regimes frequently recur after extended periods of conflicting dynamics. Standard temporal link prediction evaluations do not cleanly isolate whether a model retains access to historically predictive information when a prior regime becomes relevant again. In this work, we formalize this challenge through a controlled $\mathcal{A} \to \mathcal{B} \to \mathcal{A}$ dynamic graph recurrence benchmark parameterized by distractor duration $T_B$. Across extensive experiments, we demonstrate that continuous recurrent node representations exhibit duration-dependent degradation in historical recoverability, and that simply expanding recurrent memory capacity does not fully eliminate this temporal memory interference. We introduce the Memory-Augmented Temporal Graph Network (MA-TGN), which decouples recurrent neighborhood tracking from an addressable episodic checkpoint memory. Under the evaluated synthetic recurrence protocol, MA-TGN restores evaluated link prediction performance at recurrence onset ($k_A=0$) without requiring re-adaptation steps. Across four natural recurrence episodes each in SNAP CollegeMsg and SNAP Bitcoin-OTC, MA-TGN consistently outperforms standard continuous TGNs ($\Delta\text{AP} = +0.0583$ on CollegeMsg and $+0.1243$ on Bitcoin-OTC). Crucially, exact-edge memorization baselines (EdgeBank) remain superior when recurrence is dominated by repeated identical node pairs ($\text{AP} = 0.8763$ and $0.7753$). These findings motivate a fundamental distinction between continuous recurrent compression, exact-edge memorization, and addressable historical access under recurring temporal dynamics.
\end{abstract}
